# Worked experiments

`captures/` holds unlabeled bench binaries. `journal.jsonl` records only
whether a capture was accepted and, occasionally, one recovered scientific
fact. `inventory.txt` is the surviving sticker strip. `metrology/` contains
numeric rounding and fit checks with no wire drawings.

Recover layouts from the captures and then apply the same laws to
`/app/fragments`. Do not copy capture bytes into campaign products.
